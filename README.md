# Physical Liquids 2D

A Godot addon that adds a customizable `Liquid2D` node with physics-based liquid behavior.

## Features

- **Presets:** Ready-to-use Water and Lava presets.
- **Custom Liquids:** Customize the liquid's appearance and physical properties.
- **Ambient Waves:** Creates continuous waves across the liquid's surface.
- **Dynamic Splashes:** When an object with a `velocity` property enters the liquid, it creates a splash based on its velocity.

## Getting Started

Using the addon is simple:

1. Open the **Add Node** dialog in Godot.
2. Search for `Liquid2D` and add the node.
3. Choose a preset: Water or Lava.
4. Select Custom to configure your own liquid properties.

That's it! Your liquid is ready to use.
